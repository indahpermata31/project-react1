# Praktik React JS Dasar + Tailwind CSS

Proyek sederhana "Toko Buku Kecil" untuk modul 3.2.

## Menjalankan
```
npm install
npm run dev
```

## Pemetaan ke materi
| Materi | Lokasi |
|---|---|
| Functional component, props | `Button`, `BookCard`, `FormField` |
| useState | `App.jsx` (cart, query, sent), `Navbar.jsx` (open) |
| useEffect | `App.jsx` (judul tab mengikuti isi keranjang) |
| Event handling | `onClick`, `onChange`, `onSubmit` |
| Conditional rendering dan conditional classes | menu mobile, pesan kosong, badge level |
| Rendering list dan key | daftar buku dan link navbar |
| Flexbox dan CSS Grid | navbar, keranjang, grid katalog |
| Responsive prefixes | `sm:`, `md:`, `lg:` |
| Hover, focus, disabled | `Button`, `FormField`, link |
| Tailwind + Vite | `vite.config.js`, `src/index.css` |
